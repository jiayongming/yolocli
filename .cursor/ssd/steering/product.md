# 产品概述

YOLO CLI 是一个功能完整的命令行工具框架，用于 YOLO 模型的训练、推理和管理。它为机器学习工程师和数据科学家提供统一的工作流程，简化从数据准备到模型部署的全过程。

## 核心能力

1. **一键训练流程** - 自动化完成数据处理、模型下载、训练、验证的完整工作流，支持按比例或按样本数划分数据集
2. **多任务支持** - 统一支持目标检测(detect)、实例分割(segment)、图像分类(classify)、姿势估计(pose)四种计算机视觉任务
3. **智能设备管理** - 自动检测并优化使用 Apple Silicon (MPS)、NVIDIA GPU (CUDA) 或 CPU，支持多GPU训练
4. **Label Studio 集成** - 双向数据流支持：从 Label Studio 导入标注数据，上传数据集进行人工审核
5. **FiftyOne 可视化** - 数据集可视化、预测结果展示、Ground Truth vs Predictions 对比分析

## 目标用例

- **快速原型验证**: 使用 `quick train` 一键训练，从原始数据到可用模型
- **生产级训练管道**: 逐步控制数据划分、增强策略、优化器配置等细节
- **标注工作流管理**: Label Studio 集成实现数据标注、审核、训练的闭环
- **模型评估对比**: 批量验证多个模型，找出最佳配置

## 价值主张

- **降低入门门槛**: 交互式模式提供图形化菜单，无需记忆复杂命令
- **统一多版本支持**: 同时支持 YOLOv8 和 YOLO11，自动处理版本兼容性
- **灵活的配置系统**: YAML 配置文件 + 命令行参数 + 预设配置，满足不同场景需求
- **完整的文档和帮助**: 每个命令都有详细的中文帮助信息和使用示例
